# Artefacts

Petits outils web autonomes, hébergés sur GitHub Pages.

**Site : https://fredleroy.github.io/artefacts/**

- [Liste de courses](https://fredleroy.github.io/artefacts/courses/) — `courses/index.html` ; liste partagée dans `courses/courses.json`, ajouts et cases cochées dans le stockage local du navigateur.
- [Calculateur de patron de trousse](https://fredleroy.github.io/artefacts/trousse/) — `trousse/index.html` ; marge de couture de 1 cm par défaut.

L’ancien lien `courses.html` redirige vers `courses/`. Le déplacement conserve les données locales, car le domaine et la clé de stockage restent identiques.

Pour démarrer une nouvelle liste et réinitialiser les ajouts et cases cochées, changer `tripId` dans `courses/courses.json`.
